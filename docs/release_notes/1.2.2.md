**Có gì mới**

- Icon ứng dụng mới và giao diện Cài đặt/Giới thiệu đồng bộ hơn.
- Kéo được cửa sổ khi đang mở Cài đặt.
- Chọn cách hiển thị ảnh/video: phóng vừa cửa sổ hoặc giới hạn theo kích thước gốc.
- Kéo thanh thời gian để tua, kéo mốc A/B để chỉnh đoạn lặp; bấm lại mốc ở cùng vị trí để huỷ.
- Mở thêm file từ Explorer trên Windows vào tab của cửa sổ đang dùng.
